// Aircraft Type = Airbus A350
// Checklist Type = Reduced Normal Procedures

# AIRCRAFT AND SIMULATOR SETUP
- Time / Weather / A/C Position .. As Chosen
** --- IF FLYING ON IVAO ---
+ A/C Position .. Free of other traffic
+ IVAO Pilot Client .. Connect
- Sidestick, Throttle, Rudders .. Connected

# Cockpit Inspection
- ENG MASTER SW 1 & 2 .. OFF
- ENG START Selector .. NORM
- Landing Gear Lever .. DOWN
- Wipers .. OFF
- BAT 1 & 2, BAT EMER 1 & 2 .. Check Voltage


# Electrical Power-Up
- BAT 1 & BAT EMER 1 .. ON
- BAT EMER 2 & BAT 2 .. ON
- EXT 2 & 1 .. AUTO
- IRS 1, 2, 3 .. NAV

# Refueling and Boarding
- Exclusively use GSX's own interface for loading
- OIS > FLT OPS STS .. Simbrief Import
- FOB .. Check less than required
** --- If more FOB than required ---
+ OIS > Loadsheet .. Manually set less fuel
- GSX .. Perform Boarding etc.

# FMS Setup 1
- ACFT Status .. Check Information
- INIT Page .. Enter Flight Plan Information
+ CPNY Flight Plan .. Request, then Insert

# Aircraft Status Check
- ECAM Control > RCL ALL .. Press, Check No Messages
- ECAM Control > DISPATCH .. Press, Check No Messages
- Radio Management Panels L & R .. Both On
- Fire Test .. Perform
- APU MASTER & START SW .. ON
- Oxygen .. Check Quantity
- ENG OIL QTY .. Check
- HYD QTY .. Confirm in green box
- FLAPS .. UP & matches indication
- Speed Brake Lever .. Retract
- Accumulator Pressure .. Check
- Oxygen .. Test

# Cockpit Setup
- Overhead Panel .. Set
+ RCDR GND CTL .. ON
+ SEAT BELTS .. On once fuel loaded
- AIR DATA .. AUTO
- FMS .. NORM
- ANTI-SKID .. ON
- BARO .. Set QNH
- XPDR .. STBY
= Once APU Available
- APU BLEED .. ON
- EXT 1 & 2 .. OFF

# FMS Setup 2
- FMS Init Page .. Follow Page Layout
- Cockpit Preparation CL .. Completed

# Before Pushback
- BARO .. Check Local QNH
- ALT .. Set Initial Climb
- WXR .. Confirm AUTO
- XPDR .. AUTO & Set Squawk
- TCAS .. STBY & ABV
- Parking Brake .. Confirm Set
- Windows & Doors .. Confirm Closed
- External Equipment & Chocks .. Removed
- Before Start CL .. Down to Beacon Light
= Once Cleared For Pushback
- BEACON Light .. ON
- Before Start CL .. Completed
= Once Pushback Completed
- Parking Brake .. ON

# Engine Start
- Thrust Levers .. Confirm Idle
- ENG START Selector .. IGN START
- ENG MASTER SW 1 .. ON
= Once ENG 1 AVAIL
- ENG MASTER SW 2 .. ON
= Once ENG 2 AVAIL
- ENG START Selector .. NORM

# After Start
- APU BLEED .. OFF
- ANTI-ICE .. As Required
- APU MASTER SW .. OFF
- AUTO BRAKE RTO .. ARM
- GND Spoilers .. Arm
- Rudder Trim .. Reset
- Flaps .. As Required for Takeoff
- Trim .. Check Automatically Set
- Flight Controls .. Check
- After Start CL .. Completed

# Taxi
- Nose Light .. Taxi
- Parking Brake .. Off
- Brakes .. Test
- Taxi CL .. Completed

# Before Takeoff
- FMA Modes .. Check CLB & NAV Armed
- Speeds .. Check
- Initial Climb .. Check
- Flaps .. Check
- TCAS .. TA/RA
- TO Config .. Pushed, No Blue
- LDG Lights .. ON
- ND .. Range as required
= Once Cleared For Takeoff
- Nose Light .. TO
- Strobe Lights .. ON
- Chrono .. Start
- Lineup CL .. Completed

# Takeoff
- Pitch .. Down Halfway
- ENG 1 & 2 .. Set to 25%
= Once Engines Stabilized
- Power .. As Required For TO
- Brakes .. Release
= Speed 80 - 100 kts
- Pitch .. Neutral
= At Vr
- Pitch .. Around 15 Degrees

# After Takeoff
- Gear .. Up on positive climb
- Flaps .. Up according to speed
= Once Flaps UP
- GND Spoilers .. Disarm
- Nose Light .. OFF

# Climb
- FMA Modes .. Monitor
= Once Passing TA
- BARO .. STD
= Once Passing FL100
- LDG Lights .. OFF
- SEAT BELTS .. OFF

# Cruise
- TCAS .. BLW
- Fuel Checks .. Perform at least every hour
- Step Climbs
+ FMS > PERF > CRZ Page .. Open Step Alts Page

# Before Descend
- WX & Landing Information .. Obtain
+ A350 is landing category D
+ BARO .. Preselect local QNH
- Perf > APPR Page .. Enter Information
- Landing Performance .. Calculate
- Arrival Routing .. Enter / Check
** --- If flying ILS approach ---
+ FMS POSITION > NAVAIDS Page .. Check ILS Information
- BTV .. Programmed

# Descend
- Icing Conditions
+ Visible Moisture
+ SAT (static air temperature) .. > -40
+ TAT (total air temperature) .. < +10
+ With engines at idle .. TAT < -10
= When Passing FL250
- SEAT BELTS .. ON
= When Passing FL100
- LDG Lights .. ON
- Nose Lights .. Taxi
** --- If flying ILS approach ---
+ LS .. ON
= On Passing TRL
- BARO .. Set local QNH


# Approach
- Approach Mode .. Activate
- Configuration
+ Flaps 1 .. 12 DME THR / 4000 ft AGL
+ Flaps 2 .. 8 DME THR / 3000 ft AGL
+ Gear Down .. 6 DME THR / 2000 ft AGL
+ Below 200 kt .. 10 DME THR
= On FAF / FAP
- Flaps .. Down according to speed
- Approach Checklist .. Completed
= On Passing 2000 ft AGL
- Gear .. Down
- Speed Brakes .. ARM
= Once Cleared For Landing
- Nose Light .. TO
- Landing Checklist .. Completed

# Landing
- ECAM LDG Memo .. No Blue
= On Passing 1000 ft AGL
- Fully Stabilized
= At 40 ft AGL
- Flare .. Initiate
- Thrust .. Idle
= At 70 kts
- Reverse Thrust .. Idle
= Before Leaving RWY
- Thrust Reversers .. Stowed

# After Landing
- Speed Brakes .. Disarm
- Flaps .. UP
- WXR .. OFF
- LDG Lights .. OFF
- Nose Light .. Taxi
- Strobe Lights .. AUTO
- APU .. Start
- TCAS .. STBY
= When Entering Apron
- Nose Lights .. OFF

# Parking
- Parking Brake .. Set
- XPDR .. STBY
= Once APU Running
- ENG MASTER SW 2 & 1 .. OFF
= Once Engines Shutdown
- BEACON Light .. OFF
- Fuel Pumps .. OFF
- Seat Belt Signs .. OFF
- Parking CL .. Completed

# Shutdown
- ADIRS .. OFF
- Crew Oxygen .. OFF
- Exterior Lights .. OFF
- EXT PWR .. As Required
- APU .. OFF
- EMER EXIT Lights .. OFF
- Signs .. OFF
- Securing CL .. Completed
